# Atlas

Mission

Reduce daily administrative work in brick manufacturing businesses from hours to under 30 minutes.

Core Principles

- Enter information exactly once.
- Record data where it is created.
- Online-first.
- Zero unnecessary typing.
- Every screen has one job.
- Mobile-first.
- Never lose user data.
- Save directly to Supabase.
- Simplicity beats feature count.
- Build only validated customer needs.

Current MVP

Daily Production Recording System

Goal

Replace the manager's rough notebook, register, and Excel workflow with a simple mobile application that records labour production in under five minutes and saves directly to the office dashboard.
